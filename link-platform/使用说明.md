# 安药 · 手机 × Watch S3 × 智能药盒 实时联动

## 一键启动

- 双击 `启动联动.cmd`：打开联动大屏，可以自己在手机、药盒、手表上操作。
- 双击 `一键演示全部功能.cmd`：打开大屏后自动把全部功能演示一遍（约 2.5 分钟，26 步，上方字幕说明每一步）；也可以在大屏底部点“▶ 一键演示全部功能”，随时暂停 / 停止。
- 包内自带运行环境，电脑不需要安装任何软件。演示连接的是虚拟药盒和虚拟手表，不需要真机。
- 第一次点一下页面即开启提示音（浏览器规定先点击才能出声）。

## 三端一起提醒

到吃药时间，三端同时提醒：
- 手机：通知 + 响铃 + 震动 + 闪光（按设置）
- 药盒：对应药仓亮灯、机身震动、响铃“叮咚”，屏幕显示该吃的药和仓位
- 手表：弹出用药通知，持续短振并“嘀嘀”响，直到处理

在任意一端处理（取药并确认、手表点“在手机上打开”、通知点“我吃了 / 15 分钟后”），三端提醒一起结束。稍后、超时未吃、睡醒补提醒时也是三端一起。
“一键准备示例”会直接连好药盒和手表，药盒自动装药（每种按时吃的药一个仓位）并下发提醒。


用你自己的手机操作，电脑上的三维药盒和三维手表会即时响应；在三维模型上操作，手机也会即时更新。三端共用同一份服药状态。

## 启动

1. 双击 `启动联动.cmd`（需要 Node.js 18+）。电脑浏览器会自动打开大屏。
2. 点大屏右上角“手机扫码加入”，用手机扫码。手机和电脑需要连同一个 Wi‑Fi；首次运行时 Windows 防火墙询问，请允许“专用网络”。
3. 也可以用 USB：脚本会自动执行 `adb reverse tcp:4200 tcp:4200`，之后在手机浏览器打开 `http://127.0.0.1:4200/phone.html?k=配对码`。
4. 手机浏览器里选“添加到主屏幕”，就会像一个 App 一样全屏打开。

配对码每次启动都会更换，只有扫码的设备能操作。服务只在本机和局域网内工作，不连接云端。

## 一次完整体验

| 操作（任选一端） | 其他两端的反应 |
| --- | --- |
| 手机“现在提醒”，或到计划时刻自动触发 | 手机震动并弹出“该吃药了”；药盒对应药仓橙灯闪烁、机身震动、屏幕显示“该吃药了”；手表两次短振并弹出通知 |
| 点三维外盖 / 手机“打开外盖” | 外盖翻开，药盒屏幕提示打开几号仓 |
| 点三维药仓盖 / 手机“打开药仓” | 该仓打开；开错仓会提示应取哪一仓 |
| 点仓内药片 / 手机“取出药片” | 药片被取出，震动停止，屏幕“取药后请确认”。**取药不会自动记为已服** |
| 点手表“在手机上打开” | 手机弹出“来自 Watch S3”的确认窗口 |
| 手机“已服药”，或点药盒左侧确认键 | 记录服药时间、库存减 1；药盒指示灯转绿；手表显示确认记录；家属端同步 |
| 合上外盖 | 药盒熄灯回到待机，屏幕显示下次用药 |

### 与安药最新版同步（1.3.0）

`app/` 目录与安药 1.3.0（`F:nyao_work\cloud-sync-20261016\web`）逐字节一致。演示专用的改动都在 `public/` 里、加载时注入，不改安药源码：

- `demo-overrides.js`：家庭服务的同步状态（如“家庭服务连接正常”）不放在页面顶部，只在“设置 → 同步与访问”里显示；药盒还没连接时，打开药盒第一个盖子（外盖），手机自动弹出“连接智能药盒”窗口，在里面搜索、连接即可。已连接后开盖不再弹窗。
- `demo-pb1-modes.js`：药盒页里的“仅振动与休眠”设置。

### 误开药仓

| 操作 | 反应 |
| --- | --- |
| 打开不是当前时段的药仓（正在提醒的不是这一仓，或这一仓前后 30 分钟内没有计划） | 该仓红灯、机身轻微震动；屏幕“当前药非当前时段，是否确认服用？” |
| 单击药盒按键（屏幕下方） | 取消，不记录服药，红灯熄灭 |
| 双击药盒按键（0.6 秒内两次） | 确认服用：记到这种药最近一顿，标注“非当前时段”；那一顿到点时不再提醒 |

### 药盒屏幕三页

在三维药盒屏幕上横向拖动即滑动（也可点下方提示按钮）：

- 主页：始终显示现在时间、上次服用时间与药仓、下次服用时间与药仓。
- 左滑 → 仅振动页：按键开启 / 关闭。开启后到点只震动、不亮灯，手机不响铃不闪光。
- 右滑 → 休眠页：按键进入 / 结束休眠。休眠期间到点不提醒、不算超时；醒来（时间到、按键、或手机“我醒了”）后，把睡着时没吃的药重新提醒一次（手机通知“睡醒了，这顿药还没吃”）。

手机：安药 → 药盒 → 仅振动与休眠，可设置振动强度（轻柔 / 标准 / 醒目）、每天自动进入仅振动的时间段、小睡时长（30–120 分钟）、夜间睡眠时间段，保存后立即同步到药盒。误开药仓的红灯提示在仅振动和休眠时照常。12 秒不操作，屏幕回到主页。

其他：稍后 10 分钟（药盒熄灯、屏幕显示再次提醒时间，到点三端再次提醒；“记录 → 稍后到点”可立即触发）、这次不吃、轻柔/标准/醒目三档强度、震动和指示灯独立开关、手表通知开关、断开/重连设备、家属超时提醒、修改计划时间、库存低提醒、重置演示。

重复点击、网络重试不会重复记录或重复扣库存（每个操作带请求编号，服务端幂等处理）。

## 边界

药盒和手表是三维模型，震动、灯光、屏幕都是模拟；本包不驱动真实 PB1 药盒或 Watch S3，也不会改动安药 App 里的真实服药数据。真实 Watch S3 通知 → 手机确认已在 0.4.8 版本单独验证过。演示状态保存在 `data/state.json`，删除即可清空。

## 文件

- `server.cjs` 本地服务；`engine.cjs` 三端共享状态机（全部规则只在这里执行一次）
- `public/index.html` 电脑大屏（带外框的手机 + 三维药盒 + 三维手表 + 实时事件）
- `public/phone.html` 手机控制端
- `public/models/` 药盒 PB1 R4 与 Watch S3 模型；`public/vendor/` Three.js 0.180（MIT）与 qrcode-generator 1.4.4（MIT）
- `tests/e2e.mjs`（30 项三端联动检查）、`tests/model-click.mjs`（直接点三维模型 5 项）
